# Security policy

MediaGrab espone soltanto un endpoint HTTP locale su `127.0.0.1` e non deve essere configurato per ascoltare su interfacce di rete pubbliche.

Non inserire token, password o cookie personali nel repository.

Per vulnerabilità, aprire una segnalazione privata tramite GitHub Security Advisories invece di pubblicare credenziali o dettagli sensibili in una issue.
